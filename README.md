# 🩺 MedScript — AI-Powered Medical Consultation Assistant

MedScript is an AI-driven healthcare documentation platform that automates doctor–patient consultation transcription and generates structured clinical reports using speech recognition and NLP.

The system captures medical conversations, converts speech to text using Whisper ASR, extracts medical entities using NLP, and generates structured SOAP-style reports automatically.

---

# 🚀 Features

✅ Real-time / recorded consultation processing  
✅ Whisper-based Speech-to-Text transcription  
✅ Hindi → English translation support  
✅ Medical text correction pipeline  
✅ NLP-based symptom & medicine extraction  
✅ Structured SOAP report generation  
✅ PDF medical report export  
✅ Consultation history management  
✅ FastAPI backend architecture  
✅ Modern React dashboard UI
